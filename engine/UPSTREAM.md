# engine/src/inkling2: Inkling 2 Mini engine taken from PolyStrata

Upstream: https://github.com/simplexai-labs/PolyStrata pull request #200 (`poly: Inkling 2 Mini (inkling2 / inkling2_loop)`), head commit `6e610541f344fee87f17f7c50da4bf2fc72a997c`.
License: MIT, Copyright (c) Niko1221/Strata and VecSzn/PolyStrata contributors; the full text is in `LICENSE.PolyStrata`. The MMQ kernels it builds come from llama.cpp's ggml-cuda (MIT, The ggml authors), taken from `engine/third_party/strata-llama` (llama.cpp 3cf03257, the same pin PolyStrata uses).

Copied by `tools/port_polystrata.py`; after the copy, the other strata-poly models (GLM 5, Qwen 3.5, Gemma 4, DeepSeek V4, LFM2, Flint, Kolibri) were removed from `engine.cpp`'s dispatch. Later edits are this fork's and are in its git history.
Kernel sources the Inkling engine does not build (the Qwen engine's) were not kept; the headers were.

`--kv k8v4` (opt-in, this fork's code): 8-bit keys and 4-bit values follow the idea of NInfer's `rk8v4` KV format (Apache-2.0) and the per-block random rotation before a scalar quantizer follows TurboQuant (MIT, `turboquant` reference code); no code was copied from either. The 4-bit rule is ggml's Q4_0 (MIT, The ggml authors), written here for this plane layout.

The prompt read's embeddings on the host's threads (`INKLING2_EMBED_MT`, on by default) and `--read-mib` / `INKLING2_READ_MIB` (the host memory a read's rows take, by default by the machine's RAM, so that a long prompt is fewer reads and each layer's experts outside VRAM are copied fewer times) follow ideas in kuraneko1/Strata's strata-inkling2 (MIT): its threaded token dequantisation and its prefill staging of only the experts VRAM lacks. No code was copied; both are this fork's code.
